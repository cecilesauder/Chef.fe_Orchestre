Guide de la battue à 4 temps (Chironomie)

0. La Levée (Anacrouse)

Avant le 1er temps, respirez avec l'orchestre en levant la main droite sur le 4e temps à vide pour donner le tempo (100 BPM).

Temps 1 : Vers le BAS

Descente verticale franche jusqu'au plan de battue (niveau du plexus), suivie d'un petit rebond net (l'ictus).

Temps 2 : Vers la GAUCHE

Pour un droitier, mouvement vers l'intérieur (croise légèrement devant le buste vers la gauche).

Temps 3 : Vers la DROITE

Grand mouvement horizontal traversant vers l'extérieur (droite). C'est le temps le plus lisible pour tous les pupitres.

Temps 4 : Vers le HAUT

Remontée souple vers le haut pour préparer la chute du prochain Temps 1.

Rôle de la Main Gauche

Paume vers le bas = calmer/piano. Main qui monte paume vers le haut = crescendo. Index pointé = départ d'un pupitre.

Le score compare chaque tap au battement attendu. Jusqu’à 35 ms d’écart : précision excellente ; au-delà de 175 ms : tap hors tempo.

Vert — dans le tempo : le geste est proche du battement attendu.
Bleu — en avance : le geste arrive avant le battement ; attendez légèrement.
